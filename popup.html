01 / Font cục bộ

Cách cài font chuẩn vào Windows (nhẹ & mượt nhất):
  1. Tải file font (.ttf hoặc .otf) về máy và giải nén nếu là file .zip.
  2. Bôi đen các file font → Chuột phải → chọn "Install for all users" (Cài đặt cho mọi người dùng).
  3. Mở cài đặt Font Glass → bấm "Quét font" là dùng được ngay, không tốn RAM trình duyệt.

Quét trong tab cài đặt để hộp xin quyền không làm đóng popup.

Font từ file

⚠️ Lưu ý trước khi nạp font từ file:

Đây là phương án dự phòng chưa tối ưu bằng cài trực tiếp vào máy (vì trình duyệt phải tự nạp file font vào bộ nhớ). Nếu có thể, hãy cài font kiểu "Install for all users" vào Windows. Chỉ nên dùng mục này khi máy công ty hoặc máy bị khoá quyền cài đặt — và hãy ưu tiên file .woff2 cho nhẹ, nếu không có thì hãy chọn lọc cẩn thận.
